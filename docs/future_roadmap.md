# Future Roadmap and Deferred Tasks

This document tracks planned features, pending implementations, and deferred tasks for the SaMD Classifier.

## Pending Tasks
- **Real (non-synthetic) training data**: Currently blocked on data source. The models are presently trained on synthetic data (`synthetic-v1`).
- **Second disease (diabetes risk)**: Deferred until the version 1 (v1) pipeline and API contracts for hypertension are stable.
- **Encryption envelope**: For external/government API calls. Currently deferred. Please see the API contract documentation for more details.
